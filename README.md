# Site Design

Открытый репозиторий для совместной работы над дизайном сайта. Здесь хранятся макеты, графика, задания и результаты проверки. Исходники сайта пока не добавлены.

## Дизайнерам: как передать дизайн

1. Прочитайте [инструкцию](docs/DESIGNERS.md) и создайте Issue через шаблон «Задача на дизайн», указав страницу и цель работы.
2. Сделайте fork репозитория. В своём fork создайте папку `design/submissions/<название-задачи>/`.
3. Добавьте превью, экспорты и файл `README.md` по [шаблону](design/submissions/README.md). Макет Figma можно передать ссылкой с доступом на просмотр.
4. Откройте Pull Request в `main` этого репозитория, добавьте скриншоты и ссылку на Issue. Владелец проверит и объединит изменения.

Git устанавливать необязательно: в своём fork используйте **Add file → Upload files**, затем **Contribute → Open pull request**. Для загрузки файлов и открытия PR нужен GitHub-аккаунт. Прямая запись в основной репозиторий доступна только приглашённым участникам.

## Синхронизация для участников с Git

Клонируйте репозиторий по адресу из кнопки **Code**. Перед работой обновляйте свою ветку из `main`, создавайте отдельную ветку `design/<название-задачи>` и отправляйте изменения через Pull Request. Для fork сначала используйте **Sync fork**.

## Публичность и права

Все загруженные материалы будут общедоступны. Публикуйте только материалы, которыми вы вправе делиться; указывайте источники и лицензии сторонних шрифтов, фото и иконок. Не загружайте пароли, токены, персональные данные или клиентские материалы без разрешения. Лицензия на свободное использование материалов пока не установлена; условия использования согласуются с правообладателем.
