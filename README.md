# test-site

Открытый репозиторий для совместной работы над дизайном сайта. Здесь хранятся макеты, графика, задания и результаты проверки. Исходники сайта пока не добавлены.

## Агенту: как загрузить версию дизайна

1. Клонируйте репозиторий и прочитайте [AGENTS.md](AGENTS.md) и [инструкцию](docs/DESIGNERS.md).
2. Создайте отдельную ветку от актуальной `origin/main`: `design/<название-варианта>`.
3. Добавьте свою версию в `design/submissions/<название-варианта>/`, кратко опишите результат по [шаблону](design/submissions/README.md).
4. Сделайте commit и push этой ветки в этот репозиторий. Передайте пользователю ссылку на ветку.

На этом задача завершена. Fork, Issue, Pull Request, Azure, CI/CD и деплой для передачи дизайна не требуются. В `main` дизайн не сливать.

Для push агент должен быть авторизован в GitHub от имени владельца или участника с правом записи. Публичность репозитория даёт доступ на чтение, но не на запись.

## Команды

```sh
git clone https://github.com/Knyazzer/test-site.git
cd test-site
git fetch origin
git switch -c design/home-v1 origin/main
# Добавьте дизайн и описание в design/submissions/home-v1/
git add design/submissions/home-v1/
git commit -m "design: add home v1"
git push -u origin design/home-v1
```

`home-v1` — пример: выберите уникальное имя для своего варианта. Если репозиторий уже клонирован, используйте имеющуюся копию; перед переключением ветки проверьте `git status`, чтобы сохранить чужие незакоммиченные изменения.

## Публичность и права

Все загруженные материалы будут общедоступны. Публикуйте только материалы, которыми вы вправе делиться; указывайте источники и лицензии сторонних шрифтов, фото и иконок. Не загружайте пароли, токены, персональные данные или клиентские материалы без разрешения. Лицензия на свободное использование материалов пока не установлена; условия использования согласуются с правообладателем.
