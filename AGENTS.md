# Задачи агентов по дизайну

Область работы: дизайн сайта, макеты, графика и документация передачи в разработку. Исходники и стек сайта пока отсутствуют. Не выбирайте стек и не создавайте приложение без отдельной задачи.

1. **Агент по брифу:** уточнить аудиторию, цель страницы, контент и ограничения; записать критерии приёмки в Issue. Неизвестное отмечать как допущение.
2. **UX-агент:** подготовить структуру страницы, пользовательский путь и wireframe для desktop/mobile; описать навигацию и состояния.
3. **UI-агент:** разработать визуальное направление, компоненты, цвета, типографику и адаптивные макеты; приложить превью и исходники/ссылку на Figma.
4. **Агент по ассетам и передаче:** собрать оптимизированные изображения и SVG, источники и лицензии; описать размеры, отступы, состояния и адаптивное поведение.
5. **Агент проверки:** проверить читаемость, контраст, focus, согласованность компонентов, мобильную версию и комплектность передачи; записать замечания в PR.

## Общие правила

- Работать по конкретному Issue, в отдельной ветке и через Pull Request. Не пушить в `main` без явного поручения владельца.
- Соблюдать [инструкцию для дизайнеров](docs/DESIGNERS.md); материалы каждой задачи размещать в `design/submissions/<название-задачи>/`.
- Не менять и не удалять чужие материалы без согласованного задания.
- Не публиковать секреты, личные данные и материалы без права на публикацию.
- В итоговом PR кратко указать: что сделано, где превью, что проверено и какие вопросы остались. Не заявлять о проверках, которые не выполнялись.
